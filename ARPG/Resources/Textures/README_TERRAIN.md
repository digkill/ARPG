# Фантазийная текстура террейна

## Описание

Система текстур террейна для фантазийного мира в игре ARPG. Включает процедурную генерацию текстур и улучшенные шейдеры для создания атмосферного фантазийного окружения.

## Структура файлов

- `Assets.xcassets/FantasyTerrain.textureset/` - Asset каталог для текстуры террейна
- `Resources/Textures/generate_fantasy_terrain.py` - Скрипт для генерации процедурной текстуры
- `Resources/Textures/FantasyTerrain.png` - Сгенерированная текстура (2048x2048)

## Особенности

### Визуальные эффекты:
- **Магические волны**: Анимированные волнообразные паттерны с голубым оттенком
- **Свечение**: Легкое зеленоватое свечение на определенных участках
- **Улучшенный блендинг**: Плавное смешивание базовой и детальной текстуры
- **Процедурные вариации**: Каждый чанк террейна имеет уникальные параметры цвета и детализации

### Технические детали:
- Размер текстуры: 2048x2048 пикселей
- Формат: PNG с альфа-каналом
- Mipmaps: Поддержка через Universal.mipmapset
- UV масштабирование: Настраивается для каждого чанка

## Использование

### Регенерация текстуры:

```bash
cd ARPG/Resources/Textures
python3 generate_fantasy_terrain.py
```

Скрипт автоматически:
1. Генерирует новую процедурную текстуру
2. Сохраняет её в `Resources/Textures/`
3. Копирует в `Assets.xcassets/FantasyTerrain.textureset/Universal.mipmapset/`

### В коде:

Текстура автоматически загружается при инициализации `Renderer`. Система пытается загрузить в следующем порядке:
1. `FantasyTerrain` из Assets.xcassets
2. `FantasyTerrain.png` из Resources/Textures
3. Fallback к старой текстуре `forest_leaves_02_diffuse_4k.jpg`

## Настройка шейдера

Шейдер поддерживает следующие параметры через `Uniforms`:
- `terrainUV` (xy = масштаб, zw = смещение) - контроль тайлинга
- `terrainColorDetail` (xyz = оттенок, w = интенсивность деталей)
- `time` - для анимации магических эффектов

## Цветовая палитра

Текстура использует фантазийную палитру:
- **Темная трава**: RGB(45, 80, 35)
- **Светлая трава**: RGB(85, 140, 65)
- **Коричневая земля**: RGB(90, 70, 50)
- **Серый камень**: RGB(100, 100, 110)
- **Магический синий**: RGB(70, 100, 150)
- **Зеленый мох**: RGB(60, 100, 70)

## Зависимости

Для генерации текстуры требуется:
- Python 3.x
- Pillow (PIL): `pip install Pillow`
- NumPy: `pip install numpy`

## Примечания

- Текстура генерируется процедурно, поэтому каждый запуск создает уникальный результат
- Для консистентности рекомендуется сохранить сгенерированную текстуру в системе контроля версий
- Размер текстуры можно изменить в скрипте (по умолчанию 2048x2048)
