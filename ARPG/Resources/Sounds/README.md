# Звуковые эффекты

Поместите следующие звуковые файлы в эту папку (`Resources/Sounds/`):

## Обязательные файлы:

1. **button_click.mp3** - Звук клика по кнопке
   - Используется при нажатии на кнопки в меню и игре
   - Рекомендуемая длительность: 0.1-0.3 секунды

2. **footstep.mp3** - Звук шагов
   - Воспроизводится при движении человеческих фигур
   - Рекомендуемая длительность: 0.2-0.5 секунды

3. **menu_music.mp3** - Фоновая музыка для меню
   - Воспроизводится в главном меню
   - Рекомендуется: спокойная, атмосферная музыка
   - Длительность: любая (будет зациклена)

4. **game_music.mp3** - Фоновая музыка для игры
   - Воспроизводится во время игры
   - Рекомендуется: динамичная, игровая музыка
   - Длительность: любая (будет зациклена)

## Формат файлов:

- Формат: MP3 (рекомендуется) или другие форматы, поддерживаемые AVAudioPlayer
- Качество: 44.1 kHz, 16-bit (стандартное качество)
- Битрейт: 128-192 kbps (для музыки), 64-128 kbps (для звуковых эффектов)

## Примечание:

Если звуковые файлы отсутствуют, игра будет работать без звука, но в консоли появятся предупреждения.
